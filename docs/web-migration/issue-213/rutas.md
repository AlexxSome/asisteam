## Layouts y estados que no cuentan como páginas

[Seguro] [`apps/web/src/app/layout.tsx`](../../../apps/web/src/app/layout.tsx) define lang=es, CSS, título/description; [`apps/web/src/app/groups/[groupId]/layout.tsx`](../../../apps/web/src/app/groups/%5BgroupId%5D/layout.tsx) consulta grupo, grupos, userId y capacidad solo ADMIN. AuthLayout es un componente, no un layout de segmento. AppShell preserva drawer, foco, breadcrumb, rol compuesto y selector.

[Seguro] [`apps/web/src/app/error.tsx`](../../../apps/web/src/app/error.tsx), [`apps/web/src/app/groups/[groupId]/error.tsx`](../../../apps/web/src/app/groups/%5BgroupId%5D/error.tsx) y [`apps/web/src/app/not-found.tsx`](../../../apps/web/src/app/not-found.tsx) pasan a errorElement raíz/grupo y ruta comodín. La carga de actividades usa Suspense/LoadingState; navegación y forms usan estados compartidos. No se añade una página por cada loading/error. `forbidden()`/`notFound()` y HTML de middleware deben conservar sus mensajes sin revelar recursos ajenos; distinguir código HTTP de API del estado visual SPA en el ADR.

[Seguro] Diferencias aceptadas respecto a SSR, rutas públicas, SEO, prefijos y enlaces sensibles: [ADR](ADR.md). Los tres handlers están separados de esta cuenta en [operaciones](operaciones.md). Los límites de pantalla de doc05 permanecen: sin INT-02, directorio APO completo, CSV, cliente móvil ni offline.
